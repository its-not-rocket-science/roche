The problem

Learned state-space models — SSMs, linear recurrences, Mamba-style architectures — must satisfy Schur stability conditions to behave predictably over long sequences. Standard training does not guarantee this. Roche provides contour certificates: formal proofs, derived from Rouché's theorem, that a learned model's eigenvalues remain within the unit disc under bounded perturbation.

Rouché's theorem

Theorem (Rouché, 1862)

If f and g are analytic in and on a closed contour C, and |g(z)| < |f(z)| on C, then f and f + g have the same number of zeros inside C (counted with multiplicity).

Applied to learned dynamics: given a nominal stable model f and a perturbation g (the deviation introduced by training), Roche certifies that the perturbed model f + g retains the same zero-count inside the unit circle — that is, remains Schur-stable.

What it provides

Contour certificates

Automated Rouché-type certificates bounding the eigenvalue deviation of a learned model from a stable reference.

Reference optimisation

Joint optimisation of the reference model and perturbation bound to maximise certificate tightness.

Stability experiments

Reproducible robustness experiments on standard SSM architectures under varying perturbation regimes.

Schur stability checks

Fast, differentiable Schur stability verification for use as a training constraint or post-hoc check.

Quick start

pip install roche

from roche import ContourCertifier

certifier = ContourCertifier(reference_model=stable_ssm)
cert = certifier.certify(learned_model, perturbation_bound=0.05)

print(cert.is_valid)        # True if Rouché condition satisfied
print(cert.margin)          # slack: how much further perturbation is tolerable
print(cert.certificate)     # formal Rouché certificate object
